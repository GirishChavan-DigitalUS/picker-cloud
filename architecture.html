Picker
System Design

Full-stack real-time NYSE intraday dashboard. Python/FastAPI backend with a 1-minute scheduler for 12 tickers, 33-rule AI evaluator, 5 composite alert detectors, optional LLM commentary and on-demand Tape Read narrative. Frontend is a PWA (vite-plugin-pwa + Workbox) with Web Push notifications (VAPID via pywebpush) for Tier 1 & 2 alerts. Features InsightGrid with 8-pattern detection, MacroBanner macro alignment, per-card HTF bias + volume + signal age context, TrendStructureTimeline swimlane, and a built-in signal guide. SQLite persistence (6 tables including push_subscriptions), React/Zustand, WebSocket.

AI Evaluation Engine
Rule-based evaluator — ai/evaluator.py
Deterministic weighted-vote system backed by optional LLM commentary. Every rule that fires is named, weighted, and explained in the UI. v3 adds RSI momentum, EMA cross-imminence, and a confluence synthesiser (9-signal alignment score).
1

Receive snapshot dict

run_evaluation(ticker, df, current_price, snapshot) called after indicators are computed. snapshot contains all 30+ fields from the indicators modules.

2

Evaluate each rule

Each of the 33 rules tests one condition on the snapshot. Returns True if triggered, False otherwise. Rules have a direction (UP or DOWN) and a float weight.

3

Sum weighted votes

UP-triggered rules contribute +weight to score; DOWN rules contribute -weight. Final score determines direction. confidence = |score| / total_possible_weight.

4

LLM Commentary (optional)

If LLM_PROVIDER is set, ai/llm_commentary.py calls Gemini Flash / GPT-4o-mini / Claude Haiku / Ollama to generate a 2-sentence plain-English rationale. Rate-limited to 1 call per 2.2 s. Only fires when prediction direction or confidence shifts ≥10% — typically 2–5 calls/hour. Result stored in notes field.

5

Emit PredictionRow

Stores prediction (UP/DOWN/NEUTRAL), confidence (0–1), rules_triggered as JSON array, and optional notes (LLM commentary) into the predictions table.

6

Outcome resolution

resolve_outcomes() runs post-cycle. For predictions older than 30 min, checks if the price moved in the predicted direction and marks outcome as WIN/LOSS in the DB. Feeds future ML retrain.

LLM Commentary
Plain-English trade rationale — ai/llm_commentary.py
Optional layer that calls an LLM after each rule-engine evaluation to produce a 2-sentence intraday rationale. Disabled by default; enabled by setting LLM_PROVIDER env var.
1

Change detection

Compares new prediction to the last emitted prediction for the same ticker. Skips the LLM call unless direction flipped (UP↔DOWN/NEUTRAL) or confidence shifted ≥10 pp. Keeps calls to ~2–5/hour across 10 tickers.

2

Rate limiter

Global asyncio.Lock enforces ≥2.2 s between any two LLM calls regardless of ticker. Prevents burst rate-limit errors on free-tier API keys (Gemini free = 30 RPM).

3

Provider dispatch

Switches on LLM_PROVIDER env var to one of four async call helpers:

ProviderEnv var valueDefault modelBase URL
Google Geminigeminigemini-2.0-flash-litegenerativelanguage.googleapis.com
OpenAIopenaigpt-4o-miniapi.openai.com
Anthropicanthropicclaude-haiku-4-5api.anthropic.com
Ollama (local)ollamallama3.1localhost:11434 (configurable)
4

Silent fail

Any error (network, auth, quota) is caught, logged as a warning, and returns None. The prediction is still persisted and broadcast; only the notes field is absent. No user-visible crash.

5

UI display

When pred.notes is non-null, TickerDetail renders a purple 🤖 AI COMMENTARY block above the triggered-rules list. Commentary is plain prose summarising direction, confidence, and key signals.

Tape Read
LLM senior-trader narrative — ai/tape_read.py
On-demand layer that synthesises the full candle context snapshot into a 3-line senior-trader read. Triggered by the Generate button in the TapeReadCard panel. Shares the same provider config and rate-limiter as llm_commentary.py.
1

Candle context snapshot

Receives the fully-enriched indicator snapshot including all candle_* fields computed by indicators/candle_context.py: structure, patterns, volume character, close position, near-level tag, HH/HL, body trend, ATR-14.

2

Change detection (hash-based cache)

Hashes a 15-key "context slice" (structure, patterns, vol_char, ema_state, price_vs_vwap, rsi, scores, etc.). Returns the cached narrative if the hash is unchanged — no LLM call, no latency.

3

3-line narrative format

The LLM is instructed to respond with exactly 3 lines:
LINE 1 Tape environment (≤5 words, e.g. "Bearish breakdown below VWAP")
LINE 2 Dominant setup or risk with specific levels (≤2 sentences)
LINE 3 Next probable move + confirm/invalidate level (≤2 sentences)

4

Shared rate limiter + silent fail

Reuses the same asyncio.Lock as llm_commentary.py — combined budget across both modules stays within provider limits. Any error returns None; the frontend shows no narrative rather than crashing.

PWA Shell — vite-plugin-pwa 1.3.0
injectManifest strategy. Web App Manifest defines app name, icons (192×512 px), theme color, standalone display mode. Registered in main.tsx via virtual:pwa-register. iOS meta tags (apple-mobile-web-app-capable, status-bar-style) in index.html.

Service Worker — src/sw.ts
Compiled by vite-plugin-pwa. Handles Workbox precaching (precacheAndRoute). Listens for push events → calls showNotification() with title, body, icon, badge, tag, and ticker data. Listens for notificationclick → focuses existing app window or opens new tab, then posts NAVIGATE_TICKER message to React app.

Push Subscription Utilities — utils/pushNotifications.ts
subscribeToPush() fetches VAPID public key from /api/push/vapid-key, requests notification permission, calls pushManager.subscribe(), then POSTs the resulting PushSubscription to the backend. unsubscribeFromPush() reverses the process. isPushSubscribed() checks active subscription state.
Notification APIPushManager
📡
VAPID Sender — backend/push.py
broadcast_push(alert) loads all subscriptions from DB, filters by per-subscription ticker list (or all if null), calls webpush() via pywebpush 2.0.0 with VAPID signing. TTL=300s (stale alerts discarded). Expired subscriptions (HTTP 404/410) auto-removed. Runs fanout via run_in_executor to avoid blocking the async event loop.
